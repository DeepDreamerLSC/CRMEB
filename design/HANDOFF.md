# AhDouceur 开发交接说明

> 面向实施开发者。视觉与交互以本文与 [DESIGN.md](../DESIGN.md) 为准。

**这套设计的核心是温暖、通透、有手作感的精品咖啡品牌，实施时要同时保留品牌氛围和交易信息的清晰度。**

1. **色彩要有透光感**

   全站以咖啡棕为底，用浅棕光晕、柔和渐变和低对比细沙曲线形成层次。不要简化成一整块深棕色，也不要加重纹理。

   | 用途 | 参考色 |
   |---|---|
   | 咖啡棕主底 | `#795039` |
   | 透光浅棕 | `#AC825F` |
   | 深棕层次 | `#3E261C` |
   | 棕底文字 | `#FFF5E5` |
   | 暖白卡片 | `#FFFAF3` |
   | 卡片深棕文字 | `#553923` |

   商品条目、购物车条目，以及“我的订单”“我的拼团”卡片保留暖白底，方便阅读。

2. **字体分工要明确**

   中文栏目和少量氛围文案使用 **龙藏体 Long Cang**；品牌 **AhDouceur** 使用斜体衬线字；商品名称、规格、价格、规则和按钮说明使用清晰的系统字体。

   手写体只承担品牌气质，不用于大段说明和关键交易数字。Long Cang 字体文件和许可证已经随项目提供。英文品牌目前使用系统字体回退，不同设备会有差异；正式落地如需完全一致，应确认授权后固定字体或制作品牌矢量字标。

3. **首页保持简洁**

   保留沙漏 Logo、品牌名、一句副文案，以及两个主要入口：

   - **寻味选豆**：进入普通选购。
   - **与友共饮**：进入拼团区域。

   不再往首页堆商品列表、营销横幅和详细拼团进度。Logo 中央咖啡水滴已经缩小，实施时沿用当前 SVG 的比例；首页两个入口图标保留自然的手绘线条。

4. **商品页有两种明确布局**

   “选购”采用**左侧竖向分类＋右侧横向商品条目**；“拼团”取消侧栏，使用整行卡片。

   商品信息按名称、风味、规格、价格和操作入口排列。拼团卡片额外展示参与人数、已拼重量、目标进度和倒计时。人数与重量分别表达，不能用人数代替成团进度。

5. **规格选择必须联动**

   当前交互为：

   - 手冲豆 → 50g / 100g → 整豆或手冲研磨。
   - 意式豆 → 250g / 1kg → 整豆或意式研磨。

   切换豆类时，重置不兼容的重量和研磨选项。选中的完整规格要一直带到购物车、结算和订单，不能只展示在弹窗里。正式售价由商品数据提供，原型价格只是示例。

6. **拼团保留当前交互，真实状态由后台确认**

   发起时可用滑条选择 **400–1000g** 目标，当前步长 **50g**，期限固定 **10天**。列表、详情和“我的拼团”应使用同一份进度与截止时间；刷新页面不能重新开始计时。

   付款成功与成团成功是两个不同状态，需要分别提示。正式实现中，付款结果、累计重量、去重人数、截止时间和退款状态都以服务端为准。原型里的头像与人数包含演示数据。

7. **细节以手机使用为准**

   底部四栏固定，内容独立滚动；适配微信顶部胶囊、底部安全区和小屏。卡片采用小圆角、细描边、少阴影，主要触控区域至少 **44×44px**。保留加载、空态、失败、售罄和按钮禁用状态，不能只还原有数据时的截图。
