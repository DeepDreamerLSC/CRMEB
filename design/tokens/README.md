# AhDouceur 主题变量

单一来源（source of truth）：`design/coffee-v1/prototype.css`（Prototype 17）+ 根目录 `DESIGN.md` 的 Visual language 章节。改品牌色只改这里，再同步到各端。

## 文件

| 文件 | 用途 |
|---|---|
| `ahdouceur.css` | CSS 自定义属性。H5 商家管理后台、H5 商城、原型页直接引入 |
| `ahdouceur.scss` | 同值 SCSS 变量 + 常用混入。uni-app 小程序端全局样式引入 |

## 三层表面（surface）模型

1. **咖啡底**（coffee）——小程序四栏与弹窗的全局底面，品牌氛围
2. **暖白内容面**（card）——商品卡、购物车条目、订单/拼团面板：`#fffaf3` 底 + 深棕字
3. **纸面**（paper）——浅色基线。**商家管理后台建议以纸面为主**（长时间使用护眼），咖啡面只做登录页/侧边栏点缀

## 接入 CRMEB 的三个深度

1. **浅层**：CRMEB 后台「系统设置-主题色」填入 `#72462c`。只影响少数全局按钮，不解决风格问题，仅作起步
2. **中层**：uni-app 端全局引入本文件，覆盖 CRMEB 的主题色变量与通用类（按钮、价格、tabbar、卡片），保持其组件结构不动——性价比最高的一层
3. **深层**：首页、商品详情、拼团页按 `DESIGN.md` 的信息架构重写模板（CRMEB 默认布局的促销感与品牌调性差异大），组件样式从本文件取值

## 纪律

- 新页面一律引用变量，**不写死色值**
- 手写体（LongCang）只用于标题/情绪文案；正文、数字、价格用无衬线 + tabular-nums
- 卡片靠 1px 描边分层，不投影；投影只给弹窗/浮层
- 图标：currentColor 单线描边 1.4，手绘大图标 1.35–1.8 且微倾 ±4°
- 尊重 `prefers-reduced-motion`
